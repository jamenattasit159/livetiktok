# livetiktok — Swarm Gift Overlay

Overlay สำหรับ TikTok LIVE: เมื่อมีคนส่งของขวัญ ฝูงเคอร์เซอร์จะช่วยกันสร้างการ์ดให้คนส่ง
(ลากกรอบ วางรูปโปรไฟล์ พิมพ์ชื่อ) ของขวัญใหญ่สุดได้มงกุฎ และมีตัวนับของขวัญมุมขวาบน

**สถานะตอนนี้:** `swarm-gift-demo.html` เป็น demo ที่ใช้ข้อมูลจำลอง ยังไม่ได้ต่อกับ TikTok จริง
และยังไม่เคยทดสอบกับไลฟ์จริง เอกสารนี้คือรายการสิ่งที่ต้องเตรียมก่อนลองใช้จริง

## ลองเล่น demo

เปิดไฟล์ `swarm-gift-demo.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
กดปุ่มของขวัญด้านล่างเพื่อยิงเอง หรือติ๊ก Auto ให้สุ่มเข้ามา

## สิ่งที่ต้องเตรียม

### 1. บัญชีและอุปกรณ์

- [ ] บัญชี TikTok ที่เปิดไลฟ์ได้ และรับของขวัญได้ (TikTok กำหนดเกณฑ์เองและเปลี่ยนได้ตามประเทศ
      ที่อ้างกันทั่วไปคืออายุ 18+ และผู้ติดตามราว 1,000 คน ให้เช็กในแอปของบัญชีคุณ)
- [ ] สิทธิ์ใช้ **TikTok LIVE Studio** บนบัญชีนั้น (ไม่ใช่ทุกบัญชีที่ได้)
- [ ] คอมพิวเตอร์ Windows ที่รัน LIVE Studio กับเบราว์เซอร์พร้อมกันไหว
- [ ] บัญชี TikTok ที่สองพร้อมเหรียญเล็กน้อย ไว้ส่ง Rose ทดสอบ (เสียเงินจริง)

### 2. ตัวดึงอีเวนต์ของขวัญ (เลือกหนึ่งทาง)

TikTok ไม่มี API ทางการสำหรับอ่านของขวัญในไลฟ์ ทั้งสองทางนี้เป็นของ third-party
อาจหลุดหรือใช้ไม่ได้ชั่วคราวเมื่อ TikTok อัปเดต

| ทาง | ต้องติดตั้ง | เหมาะกับ |
|---|---|---|
| **TikFinity** (แอปเดสก์ท็อป) | แอป TikFinity แล้วล็อกอินด้วยชื่อ TikTok | ไม่อยากรันเซิร์ฟเวอร์เอง หน้า overlay ต่อ WebSocket ในเครื่องของ TikFinity ได้ตรง ๆ |
| **TikTok-Live-Connector** (ไลบรารี Node.js) | Node.js + เขียนเซิร์ฟเวอร์ตัวเล็กส่งอีเวนต์ต่อให้หน้า overlay | อยากคุมเองทั้งหมด ไลบรารีนี้พึ่งบริการ sign ของ third-party ซึ่งอาจมีโควตาหรือต้องใช้ API key |

ทั้งสองทาง **ไม่ต้องใช้รหัสผ่าน TikTok** ใช้แค่ชื่อบัญชีที่กำลังไลฟ์อยู่

### 3. โค้ดที่ยังต้องเขียนเพิ่ม

demo มีจุดรับอีเวนต์จุดเดียวคือฟังก์ชัน `onGift({name, avatar, gift, count})` งานที่เหลือคือ

- [ ] **ตัวเชื่อม:** รับอีเวนต์ของขวัญจากทางที่เลือกในข้อ 2 แล้วเรียก `onGift`
      โดยใช้ชื่อเล่น รูปโปรไฟล์ และจำนวนจากอีเวนต์จริง
- [ ] **จับคู่ของขวัญ:** ตาราง `GIFTS` ใน demo ใช้ชื่อและราคาเหรียญที่สมมติขึ้น
      ต้องแมปของขวัญจริง (ตามราคาเหรียญในอีเวนต์) เข้า 6 ระดับ รวมถึงของขวัญที่ไม่อยู่ในรายการ
- [ ] **คอมโบ:** ของขวัญราคาถูกกดรัวได้ อีเวนต์จะมาหลายครั้งระหว่างคอมโบ
      ต้องรอจนคอมโบจบแล้วสร้างการ์ดใบเดียว ไม่อย่างนั้นจะได้การ์ดซ้ำและนับเกิน
- [ ] **โหมดไลฟ์:** ซ่อนแผงปุ่มทดสอบและปิด Auto เมื่อใช้งานจริง
- [ ] **ต่อใหม่อัตโนมัติ:** ถ้าการเชื่อมต่อหลุดกลางไลฟ์ ให้ต่อใหม่เองและแสดงสถานะให้คนไลฟ์เห็น

### 4. เอา overlay ขึ้นจอไลฟ์

- [ ] เปิดหน้า overlay จากที่อยู่ที่ LIVE Studio เข้าถึงได้ (เซิร์ฟเวอร์ในเครื่อง หรือ GitHub Pages)
- [ ] ใน LIVE Studio ตั้งผืนผ้าใบแนวตั้ง 9:16 (1080×1920)
- [ ] เพิ่ม overlay เป็นแหล่งภาพ: **Window capture** ของหน้าต่างเบราว์เซอร์ (ง่ายสุด)
      หรือผ่าน OBS Browser Source + Virtual Camera ถ้าต้องการให้พื้นหลังโปร่งใสทับกล้อง
- [ ] เพิ่มเสียงของเบราว์เซอร์ในตัวผสมเสียง ถ้าต้องการให้คนดูได้ยินเสียงคลิก
      (เสียงจะเริ่มหลังคลิกในหน้า overlay หนึ่งครั้ง)
- [ ] จัดวางส่วนที่เหลือของจอ เช่น กล้อง วิดีโอพื้นหลัง โลโก้

### 5. ทดสอบก่อนไลฟ์จริง

- [ ] เปิดไลฟ์ทดสอบ แล้วส่ง Rose จากบัญชีที่สอง ดูว่าการ์ดขึ้น ชื่อและรูปถูกคน ยอดนับตรง
- [ ] ส่ง Rose รัวเป็นคอมโบ ดูว่าได้การ์ดใบเดียวและนับจำนวนถูก
- [ ] ปิดแล้วเปิดตัวดึงอีเวนต์กลางไลฟ์ ดูว่า overlay กลับมาทำงานเอง
- [ ] ดูผ่านมือถืออีกเครื่องว่าคนดูเห็นภาพและได้ยินเสียงตามที่ตั้งใจ

## ข้อควรระวัง

- **ชื่อและรูปของคนดูขึ้นจอ:** ใครส่งของขวัญ ชื่อและรูปโปรไฟล์ของเขาจะออกไลฟ์ทันที
  รวมถึงชื่อหรือรูปที่ไม่เหมาะสม ควรมีวิธีซ่อนการ์ดหรือบล็อกรายชื่อ
- **กฎของ TikTok:** TikTok เข้มกับไลฟ์ที่ปล่อยเกมรันโดยไม่มีคนอยู่หน้าจอ
  และการขอของขวัญซ้ำ ๆ แบบอัตโนมัติ ควรอยู่หน้ากล้องและคุยกับแชต
  เครื่องมือ third-party ไม่ช่วยป้องกันหรืออุทธรณ์การถูกจำกัดไลฟ์ได้
- **ยอดนับหายเมื่อรีเฟรช:** ตัวนับเก็บในหน่วยความจำของหน้าเท่านั้น
- **จอเต็ม:** การ์ดใหม่จะไล่การ์ดเก่าที่มันทับ การ์ดใบใหญ่สุดกวาดการ์ดเล็กออกเกือบหมดจอ
- **ของขวัญเข้ารัวมาก:** มีเคอร์เซอร์ 6 ตัว ของขวัญที่เกินจะรอคิว ช่วงพีกการ์ดอาจขึ้นช้ากว่าของขวัญจริง
